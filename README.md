## Aperçu

Site vitrine et centre de formation en ligne de **Benjamin Kasereka Vinyatsi**, expert humanitaire de terrain (7+ ans, 6 pays à haut risque) en Supply Chain, Logistique, Audit, Finance et Gestion Administrative & Ressources Humaines — et fondateur de **BK-BOOST Ltd.**, formations certifiantes **100 % pratiques**. Conçu comme une expérience premium (animations soignées, design system cohérent, parcours d'inscription jusqu'au paiement) pour convertir la visite en contact qualifié.

## Fonctionnalités

**Portfolio & pôles d'expertise**
- Mise en récit du parcours professionnel (missions humanitaires, résultats chiffrés)
- 5 pôles d'expertise détaillés : Supply Chain, Logistique, Audit, Finance & Ressources Humaines, Data Analysis, Langues

**Centre de formation BK-BOOST Ltd.**
- 7 formations certifiantes 100 % pratiques (IA, Logistique & Supply Chain, Finance, Gestion Administrative & RH, Audit)
- Grille tarifaire dynamique avec offre de lancement et compte à rebours
- Formulaire d'inscription imprimable / envoyable par email (EmailJS)
- Prise de contact instantanée par WhatsApp, pré-remplie par formation et moyen de paiement

**Expérience & performance**
- Design responsive, animations Framer Motion (diaporama, transitions de page, micro-interactions)
- Navigation multi-pages fluide avec React Router
- Images optimisées, chargement rapide

## Structure du projet

```
src/
├── components/
│   ├── layout/       # Navbar, Footer
│   ├── sections/      # Hero, pôles d'expertise, formations, etc.
│   └── ui/             # Composants réutilisables (formulaires, compteurs…)
├── data/               # Contenu structuré (formations, missions, tarifs…)
├── pages/              # Pages routées (Formations, Détail, Formulaire imprimable)
└── App.jsx             # Déclaration des routes
```

## Démarrage local

```bash
# Installation des dépendances
npm install

# Serveur de développement
npm run dev
```

Le site est disponible sur `http://localhost:5173`.

```bash
# Build de production
npm run build

# Prévisualiser le build
npm run preview
```

## Déploiement

Le projet est prêt pour un déploiement statique sur **Vercel** (rewrites SPA déjà configurées dans `vercel.json`). Toute plateforme supportant Vite (Netlify, Cloudflare Pages…) fonctionne également.
